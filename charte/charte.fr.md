# Charte de contribution Softer Software

> **Version 0, expérimentale.** Elle sert à tester le principe sur une seule application, Card Games. Elle sera revue à la lumière de cette expérience, puis traduite en anglais.

## L'idée

Les joueurs demandent des jeux ou des améliorations. Des contributeurs les construisent. Ceux qui le souhaitent remercient avec un peu d'argent, et cet argent est partagé entre les contributeurs selon l'effort fourni.

Ce n'est pas un travail rémunéré au prix du marché : plutôt de quoi offrir un café de temps en temps.

## Comment ça marche

1. **Demander.** Une demande se fait depuis l'application. Elle devient une issue sur GitHub.
2. **Estimer.** Chaque demande retenue reçoit une taille d'effort : XXS, XS, S, M, L ou XL (1, 2, 3, 5, 8 ou 13 points). Une demande plus grande que XL est découpée.
3. **Construire.** Un contributeur prend une issue, ouvre une pull request et annonce sa taille. On peut contribuer avec ou sans assistant de code ; l'outil reste à la charge de chacun.
4. **Valider.** Benjamin Layet relit, accepte ou refuse, et confirme la taille. Un refus est expliqué dans la pull request.
5. **Remercier.** Les remerciements reçus sont partagés au prorata des points des contributions acceptées.

## Engagements

- Pas de publicité, pas de revente de données.
- Tout est public : demandes, tailles, validations, sommes reçues et versées.
- Rien n'est garanti : une contribution peut ne rien rapporter.

## À l'essai

Ces points seront fixés pendant l'expérience :

- où et comment les remerciements sont reçus et versés ;
- à quelle fréquence le partage est fait ;
- la licence du code et les droits des contributeurs.

## Modifier la charte

La charte vit dans ce dépôt. Toute modification passe par une pull request.
